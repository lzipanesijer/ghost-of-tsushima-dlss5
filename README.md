## Overview

This mod injects NVIDIA DLSS 5 upscaling and Frame Generation into Ghost of Tsushima DIRECTOR'S CUT, delivering native-quality visuals at a fraction of the rendering cost with minimal latency impact.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ghost of Tsushima DLSS 5** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **DLSS Super Resolution** | AI upscaling from 50% render resolution to native quality output |
| **Frame Generation** | Doubles effective frame rate using AI-synthesized intermediate frames |
| **DLAA Mode** | Full-resolution anti-aliasing for maximum fidelity without upscaling |
| **HDR Compatibility** | Preserves tone-mapping metadata through the DLSS pipeline |
